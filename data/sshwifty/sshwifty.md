## Overview

Sshwifty is an SSH and Telnet connector designed for web browsers, enabling browser-based access to SSH and Telnet services.

## Features

- SSH connector for the web
- Telnet connector for the web
- Browser-based access
- Written in Go
- Docker support
- Live demo available

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker.
