## Overview

Warpgate is a fully transparent SSH, HTTPS, Kubernetes, MySQL, and Postgres bastion/PAM (Privileged Access Management) solution that doesn't require additional client-side software.

## Features

- SSH bastion/PAM
- HTTPS bastion/PAM
- Kubernetes bastion/PAM
- MySQL bastion/PAM
- Postgres bastion/PAM
- No client-side software required
- Written in Rust
- Docker support

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted via Docker.
