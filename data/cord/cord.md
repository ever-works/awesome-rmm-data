## Overview

CoRD is an open source Remote Desktop Protocol (RDP) client for macOS that provides an alternative to Microsoft's Remote Desktop Connection for Mac.

## Features

- RDP client for macOS
- Connect to Windows Remote Desktop Services
- Fullscreen mode
- Multiple simultaneous connections
- Keyboard shortcuts
- Address book for saved connections

## Pricing
