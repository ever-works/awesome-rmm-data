## Overview

PromoProxy is a free cloud Secure Web Gateway that provides content filtering and web security protection for users and devices.

## Features

- Cloud-based Secure Web Gateway
- Content filtering and web security
- Free plan supports up to 5 users
- 1 GB of data per day on free tier
- Suitable for small business and MSP deployments

## Pricing Model

Free tier includes up to 5 users and 1 GB per day. Paid plans available for larger deployments.

## Deployment

Cloud-hosted service.
