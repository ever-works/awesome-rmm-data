## Overview

xpra is an open source remote display server and client for X11 applications, allowing individual applications or full desktops to be forwarded from a remote host to a local display.

## Features

- Remote X11 application forwarding
- Persistent sessions that survive disconnection
- Seamless window mode
- Session resumption after network loss
- HTML5 client support
- SSH tunneling support
- PulseAudio audio forwarding
- IPv6 support
