## Overview

Firezone is a secure remote access gateway that supports the WireGuard protocol, providing secure connectivity for remote teams and devices.

## Features

- WireGuard protocol support
- Web GUI
- 1-line install script
- Multi-factor authentication (MFA)
- Single sign-on (SSO)
- Written in Elixir
- Docker support

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted via Docker.
