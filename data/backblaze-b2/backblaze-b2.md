## Overview

Backblaze B2 Cloud Storage is an S3-compatible object storage service designed for backup, data archiving, and cloud storage needs.

## Features

- S3-compatible API for integration with existing backup tools
- 10 GB free object storage with no expiration
- Unlimited free time for stored data
- Access via APIs, CLI, and third-party integrations
- Suitable for MSP backup storage and disaster recovery

## Pricing Model

Free tier includes 10 GB of object storage indefinitely. Paid storage beyond the free tier is charged per GB per month, with downloads also billed per GB.

## Deployment

Cloud-hosted service.
