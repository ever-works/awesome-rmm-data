## Overview

TigerVNC is a high-performance, open source VNC implementation for remote desktop access and control across different platforms.

## Features

- High-performance remote desktop access
- Cross-platform support (Windows, Linux, macOS)
- Built-in encryption support
- File transfer
- Multiple simultaneous connections
- Session persistence
- IPv6 support

## Pricing

Free and open source software.
