## Overview

ManageEngine Endpoint Central MSP is a unified endpoint management and security platform built for managed service providers to manage multiple client networks from a single console.

## Key Features

- Asset Management
- Billing
- Multi Tenancy
- Reporting And Analytics
- Remote Access
- File Transfer
- Remote Printing
- Multi Platform
- Patch Management
- Software Deployment
- IT Asset Inventory

## Pricing

Starts from $2 per endpoint per month. Free trial available.
