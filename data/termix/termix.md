## Overview

Termix is a clientless web-based server management platform that provides SSH terminal access, tunneling, and file editing capabilities through a web browser.

## Features

- Clientless web-based server management
- SSH terminal
- Tunneling
- File editing capabilities
- Browser-based access
- Docker support

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted via Docker.
