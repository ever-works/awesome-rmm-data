## Overview

HomeButler installs and manages a curated catalog of applications via Docker Compose, maps containers and exposed ports, verifies backup restores, and reports changes since the last run.

## Features

- Docker Compose application management
- Container and port mapping
- Backup restore verification
- Change reporting
- CLI, JSON, web, and MCP interfaces
- Written in Go
- Docker support

## Pricing

Free and open-source under the MIT license.

## Deployment

Self-hosted via Docker.
