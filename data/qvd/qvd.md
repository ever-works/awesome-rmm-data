## Overview

QVD (QVD Virtual Desktop) is an open source Linux VDI platform that delivers virtual desktops to end users over the network.

## Features

- Virtual desktop infrastructure for Linux
- Remote desktop access to virtual machines
- HTML5 client access via browser
- Multiple connection protocol support
- Centralized management console
- User and group management
