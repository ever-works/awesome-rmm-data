## Overview

Localtonet is a multi-protocol tunneling service supporting HTTP, TLS, TCP, UDP, file servers, and proxy tunnels.

## Features

- Multi-protocol tunneling (HTTP, TLS, TCP, UDP)
- File Server support (SFTP, WebDAV)
- Proxy Tunnel (HTTP, SOCKS5, Shadowsocks, VLESS)
- Free plan: 1 tunnel, 1GB/month bandwidth, 30 min timeout

## Pricing

Free plan includes 1 tunnel, 1GB/month bandwidth, 30-minute timeout (excluding HTTP Tunnels). Paid plans available.
