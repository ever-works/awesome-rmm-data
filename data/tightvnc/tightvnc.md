## Overview

TightVNC is a free, open source remote desktop application using VNC (Virtual Network Computing) technology for viewing and controlling remote computers.

## Features

- Remote desktop viewing and control
- Cross-platform server and client (Windows, Linux)
- File transfer
- Built-in compression for low-bandwidth connections
- HTTP access via Java applet
- Password authentication
