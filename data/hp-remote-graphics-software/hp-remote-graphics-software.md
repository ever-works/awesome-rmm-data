## Overview

HP Remote Graphics Software (RGS) enables remote access to high-performance workstations, allowing users to run graphics-intensive applications from remote locations.

## Features

- Remote access to HP Z Workstations
- High-performance graphics transmission
- Support for 3D modeling and CAD applications
- File transfer between client and host
- Audio support
- Multi-monitor support

## Pricing

Commercial software; sender is free on HP Z Workstations, receiver is a free download.
