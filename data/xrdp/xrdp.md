## Overview

xrdp is an open source Remote Desktop Protocol (RDP) server for Linux and Unix-like systems, enabling remote desktop access from Windows RDP clients and other RDP-compatible clients.

## Features

- RDP server for Linux/Unix
- Full desktop session over RDP
- Compatible with Windows Remote Desktop Connection
- Support for X11 and Xorg
- Session management
- TLS encryption support
- Audio redirection
- Clipboard sharing
