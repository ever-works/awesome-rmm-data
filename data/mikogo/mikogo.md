## Overview

Mikogo is screen sharing and remote support software that enables online meetings, web conferencing, and remote desktop access for technical support and collaboration.

## Features

- Screen sharing and remote control
- Online meetings and web conferencing
- Cross-platform support (Windows, macOS, Linux, iOS, Android)
- File transfer during sessions
- Session recording
- Remote support with access permission request

## Pricing

Free version available with limited features; paid plans for business use.
