## Overview

ShellHub is a modern SSH server for remotely accessing Linux devices via command line using any SSH client, or through a web-based user interface. It serves as an alternative to traditional sshd.

## Features

- Modern SSH server
- Command-line access via any SSH client
- Web-based user interface
- Alternative to sshd
- Docker support

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted via Docker.
