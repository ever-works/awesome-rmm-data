## Overview

Kaseya 365 is a suite covering RMM, PSA, backup, security, and documentation for MSPs, sold as per-endpoint and per-user bundles.

## Features

- RMM (Remote Monitoring and Management)
- PSA (Professional Services Automation)
- Backup
- Security
- IT documentation
- Per-endpoint and per-user bundles

## Pricing

Paid - per-endpoint and per-user bundles.
