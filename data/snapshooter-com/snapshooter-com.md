## Overview

SnapShooter is a backup solution supporting multiple cloud providers and S3-based storage destinations.

## Features

- Backup support for DigitalOcean, AWS, Lightsail, Hetzner, and Exoscale
- Direct database, file system, and application backups
- Backups stored to S3-based storage
- Free plan includes daily backups for one resource

## Pricing

Freemium: a free plan with daily backups for one resource, with paid tiers for additional resources and features.
