## Overview

x11vnc is an open source VNC server that exports an existing X11 desktop session for remote access, allowing users to view and control their current desktop from another computer.

## Features

- Shares existing X11 desktop (not a virtual session)
- Remote desktop viewing and control
- File transfer
- HTTP access via embedded Java viewer
- SSL/TLS encryption support
- Multiple concurrent connections
- Remote cursor display

## Pricing
