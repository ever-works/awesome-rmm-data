## Overview

Apache Guacamole is a clientless remote desktop gateway that supports standard protocols like VNC and RDP, allowing users to access remote desktops through a web browser without installing client software.

## Features

- Clientless remote desktop gateway
- Supports VNC and RDP protocols
- Browser-based access
- No client software required
- Written in Java and C

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted.
