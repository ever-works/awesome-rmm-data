## Overview

OpenUEM is an open-source remote monitoring and management platform for workstations. It provides inventory, software and OS deployment, patch management, remote control, and compliance capabilities for Windows, Linux, and macOS endpoints.

## Deployment

Self-hosted or SaaS hosted in France.

## Key Features

- Inventory management
- Software deployment
- OS deployment
- Patch management
- Remote control
- Compliance management
- Web user interface for managing endpoints and agents
- Agent support for Windows, Linux, and macOS
