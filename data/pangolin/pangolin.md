## Overview

Pangolin is an identity-aware tunneled reverse proxy with a dashboard UI, access control, and WireGuard-based tunnels, serving as an alternative to Cloudflare Tunnel and Tailscale.

## Features

- Identity-aware tunneled reverse proxy
- Dashboard UI
- Access control
- WireGuard-based tunnels
- Alternative to Cloudflare Tunnel and Tailscale
- Docker support

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker.
