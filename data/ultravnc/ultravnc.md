## Overview

UltraVNC is a free, open source remote desktop administration tool for Windows that enables remote viewing and control of computers over a network.

## Features

- Remote desktop viewing and control (Windows)
- File transfer between client and server
- Integrated chat during sessions
- Built-in encryption
- Remote printing
- Screen blanking
- Multiple monitor support
- Java viewer for browser-based access
