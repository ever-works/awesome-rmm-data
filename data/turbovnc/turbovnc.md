## Overview

TurboVNC is a VNC implementation optimized for 3D graphics and video applications, using VirtualGL for hardware-accelerated OpenGL rendering over remote connections.

## Features

- High-performance 3D graphics over VNC
- Hardware-accelerated OpenGL via VirtualGL
- Cross-platform support
- JPEG compression for low-bandwidth connections
- File transfer
- Encryption support

## Pricing

Free and open source software.
