## Overview

Cardea is an SSH bastion server that provides access control, session recording, and optional TPM-backed key protection for remote management of computer systems.

## Features

- SSH bastion server functionality
- Access control policies
- Session recording capabilities
- Optional TPM-backed key protection
- Written in Go
- Docker support

## Pricing

Free and open-source under the EUPL-1.2 license.

## Deployment

Self-hosted via Docker.
