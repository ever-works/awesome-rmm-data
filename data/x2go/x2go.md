## Overview

X2Go is an open source remote desktop solution for Linux systems, based on NX technology, that provides fast and secure access to remote graphical desktops and applications.

## Features

- Remote desktop access for Linux
- Session suspension and resumption
- Low-bandwidth optimization
- SSH tunneling for security
- File transfer
- Audio support
- Printing support
- Client support for Windows, macOS, Linux
