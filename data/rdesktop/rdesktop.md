## Overview

rdesktop is an open source Remote Desktop Protocol (RDP) client for Linux and Unix systems that enables connections to Windows computers running Remote Desktop Services.

## Features

- RDP client for Linux and Unix
- Connect to Windows Remote Desktop Services
- Fullscreen and windowed modes
- Audio redirection
- File system redirection
- Smart card support
- Printer redirection
